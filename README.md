# Notepad

WPF-додаток для роботи з нотатками, розроблений на платформі .NET 8.0 з використанням архітектурного патерну MVVM.

## Можливості

- Створення, редагування, збереження та видалення нотаток
- Форматування тексту: шрифт, розмір, жирний, курсив, підкреслення, колір
- Пошук нотаток за заголовком та вмістом у реальному часі
- Автозбереження через 3 секунди після зупинки введення
- Скасування змін (Undo) з обмеженням на 50 записів
- Двомовний інтерфейс (українська / англійська)
- Збереження даних у форматі JSON

## Вимоги

- Windows 10 або новіша
- .NET Desktop Runtime 8.0+

## Клавіатурні скорочення

| Комбінація | Дія |
|---|---|
| Ctrl+N | Нова нотатка |
| Ctrl+S | Зберегти |
| Ctrl+Z | Скасувати |
| Ctrl+Delete | Видалити |
| Ctrl+B | Жирний |
| Ctrl+I | Курсив |
| Ctrl+U | Підкреслення |

## Структура проєкту

```
Notepad/
├── Models/          — модель даних (Note.cs)
├── ViewModels/      — логіка (MainViewModel.cs, BaseViewModel.cs)
├── Views/           — інтерфейс (MainWindow.xaml)
├── Services/        — робота з файлами (NoteService.cs)
├── Commands/        — командний патерн (RelayCommand.cs)
├── Localization/    — словники перекладів
└── Themes/          — стилі оформлення
```

## Збірка та запуск

```bash
dotnet build
dotnet run --project Notepad
```
